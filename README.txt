ZOHA TOURS WEBSITE
==================

Files
- index.html: complete website structure and content
- style.css: responsive styling, layout and animations
- script.js: mobile navigation, reveal-on-scroll effects and WhatsApp booking form

How to run
1. Keep all three files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. To publish, upload the folder to your hosting provider (for example, Vercel static hosting, Netlify or GitHub Pages).

Before publishing
- Replace the sample vehicle photography URLs in index.html and style.css with Zoha Tours' own licensed vehicle and chauffeur photographs for the strongest brand result.
- Confirm the company description, routes, fleet availability, operating hours and any service claims.
- The booking form opens WhatsApp at +973 3309 4308 with the entered details. It does not create an automatic reservation.
- The logo is a typographic placeholder. Replace it with the official Zoha Tours logo asset when available.

No build tools or frameworks are required.
